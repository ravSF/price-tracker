⚙️ Setup & GitHub Secrets required

1.Follow the README to create your GitHub repo and enable GitHub Pages.
2.Sign up for free API keys at scraperapi.com (1,000 req/mo free) and serpapi.com (100 searches/mo free).
3.Add all 5 secrets to your GitHub repo under Settings → Secrets → Actions:
GMAIL_USER
GMAIL_APP_PASSWORD
ALERT_EMAIL
SCRAPER_API_KEY
SERP_API_KEY
After adding products here, also commit products.json to your repo so the Python script can find them.
